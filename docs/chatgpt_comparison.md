# 写真をChatGPTに送って聞く場合との比較

同じ手持ちの写真と同じ相談文で、ChatGPTとSkinFitの答えを比べた記録です。ChatGPTの答えに書かれた事実は、メーカーの公式ページを開いて1項目ずつ照合しました。

結論を先に書きます。確かめた範囲では、ChatGPTの答えは価格・効能表示・使用感の点で公式ページと合っていました。差が出たのは、聞くたびに推す商品が変わる点、有効成分の重なりに触れない点、入れ替える手持ちとの使用感の違いを比べない点です。

## 条件

| 項目 | 内容 |
|---|---|
| 実施日 | 2026-10-15 |
| ChatGPT | 一時チャット、Web検索あり、思考の深さ「中程度」。モデル名は〔要: モデル名〕 |
| 写真 | 本人の手持ちを撮った1枚。写っている商品は〔要: 写真に写っている商品名〕 |
| 照合の方法 | メーカーの公式ページを直接開いて照合した。作業環境ではWeb検索が組織のポリシーで使えなかったため、検索結果の一覧は見ていない |

聞き方Aは、普通の人が聞きそうな書き方です。同じ文を、新しいチャットで3回送ります。

```
写真は、私が今使っているスキンケアです。
乾燥による小じわが気になっています。
3,000円以内で、ベタつかない化粧水を1本選んでください。
今の化粧水は替えてもかまいません。
```

聞き方Bは、根拠をはっきり求める書き方です。1回送ります。

```
（聞き方Aの文のあとに続けて）
写真の手持ちそれぞれの全成分を、メーカー公式の表示どおりに示してください。
選んだ商品の全成分、税込価格、効能表示の原文も、出典URL付きで示してください。
```

## 見えたこと（聞き方A・2回分の時点）

- 事実の正しさ：価格・効能表示・使用感・保湿成分は、確かめた範囲で公式ページと合っていた。SkinFitの価値を「ChatGPTの誤りを正す」ことに置くのは、この結果からは言えない
- 結論のぶれ：1回目はキュレル、2回目はコラージュを推した。どちらを選ぶべきかを並べて比べる説明は無かった
- 有効成分の重なり：2回目の候補と手持ちの乳液は、同じトラネキサム酸を含む。重なること自体は問題ではないが、セットとして見るなら知っておきたい情報なのに、触れていなかった
- 入れ替える手持ちとの比較：1回目は、さっぱりタイプの化粧水を、とろみのある化粧水に替える案だった。ベタつかないものを頼んだのに、今の化粧水より重くなりうることは書いていなかった
- 手持ちの読み取り：1回目と2回目で、手持ちの数え方が食い違った

SkinFitでは、この差に応えるために次の表示を足した。
- 候補を並べ、1位と2位の差を、固定の規則で決めた観点で1文にする
- 有効成分の重なりと、入れ替えで手放す有効成分を示す
- 入れ替える手持ちと候補の、メーカーの使用感の説明を並べる
- 手持ちのステップ × 成分の系統の表に、全成分の出典リンクを付ける
